# User Customization Rules

Rule 1: Use 60-30-10 design rule and strictly maintain that
Rule 2: Instead of emojis, use SVGs from http://svgrepo.com/
Rule 3: Avoid having hover glow animations
Rule 4: Do not use iconography but use SVGs
Rule 5: All terminal commands are approved
Rule 6: After every change, push to GitHub
Rule 7: For every change made, create and merge a PR
Rule 8: For every change, open and close at least 3 to 4 GitHub issues
Rule 9: Every Python script run in terminal or PowerShell does not need approval (automatically approve)
Rule 10: All PowerShell and terminal commands are approved
Rule 11: All Git-related commands are approved
Rule 12: Every project must include a README.md explaining the full project architecture, features, and directory structure
Rule 13: README.md must be updated whenever a new feature, component, or directory is added to the project
Rule 14: Every project must include a .gitignore and .gitkeep files in empty directories where appropriate
